## 🛠️ Detalles de la Arquitectura del Sistema
Esta aplicación fue construida bajo los más altos estándares de desarrollo móvil exigidos por la industria, asegurando un rendimiento óptimo en segundo plano para el procesamiento de coordenadas:

*   **Lenguajes de Desarrollo:** Kotlin / Java (Android Studio).
*   **Patrón de Arquitectura:** MVVM (Model-View-ViewModel), garantizando la separación de responsabilidades y modularidad limpia.
*   **Componentes Clave:** Consumo asíncrono de servicios intermedios (WCF), parseo de tramas lógicas y renderizado dinámico sobre APIs de mapas.
